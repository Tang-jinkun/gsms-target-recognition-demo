# GSMS 原型设计输入

> 用途：喂给原型设计工具。**只描述屏幕上看得见的东西**——设计规范、各页布局、屏上字段、状态、交互流。
> **不含**任何后端细节（端点、数据格式、轮询/流式、安全实现、状态架构）——这些在另一份《GSMS 各页面前端设计要求（对接后端）》里，原型阶段不需要。
> 原则：**原型要表达"显示什么"，不表达"怎么来的"。**

---

## 1. 设计规范（强制遵守，不得偏离）

- **色彩**：slate=主 UI 色；white=面板背景；teal/emerald=地图与成功；amber=运行中/警告；red=失败/错误；sky=提示。不用大面积渐变、装饰背景、营销视觉。
- **间距与圆角**：面板内边距舒适（约 12–16px）；卡片中圆角；细灰边框；阴影只用于地图浮层和小卡片。**禁止卡片套卡片**——区块之间用分隔线，不要嵌套边框盒。
- **字体层级**：无衬线（Inter 风格）。页面/区块标题=小号加粗；分组标签=更小号、大写、灰色；辅助/元数据=最小号灰字。**工作台内不用大标题/hero 字**。
- **图标**：统一图标库风格（lucide），纯图标按钮要有可读的悬浮提示/无障碍标签。
- **列表项次级操作**：默认隐藏，**鼠标悬停或聚焦时才显形**（保持静态界面干净）。
- **密度**：科研工具风格，信息密度优先但不拥挤；冷静、可扫描、低干扰。
- **桌面端**：按桌面三栏设计（建议 ≥1280px）。不做手机端重排；窄屏可横向滚动。

### 通用状态（每个数据区域都要画出来）
- **加载中**：轻量占位/转圈。
- **空**：一行虚线提示框，说明"这里还没有内容/下一步做什么"。
- **错误**：就近的浅红/琥珀提示条，**不弹全局弹窗**，不阻塞其他面板。
- **选中**：列表项选中态（高亮边框/底色）。

---

## 2. 顶部导航（所有页面共用）

顶部系统导航栏，从左到右：

```
GSMS    工作台 | 数据管理 | Skills | 设置            用户入口
```

- 当前所在页对应导航项为**选中态**。
- 导航只切换页面，不放"运行/停止/导出"等操作按钮。
- 右侧用户入口：头像/用户名占位。
- （可选）一个轻量"后端在线/离线"小指示点。

## 3. 智能工作台

**布局**：三栏。左=资源面板（图层/文件/InVEST 三 Tab）｜中=智能画布（Agent / Map / Split 三视图）｜右=运行信息（任务状态 + 日志）。
默认进入显示 **Agent 视图**。

```
┌ 顶部导航 ─────────────────────────────────────────┐
├──────────────┬──────────────────────┬─────────────┤
│ 左 资源面板    │ 中 智能画布            │ 右 运行信息   │
│ [图层][文件]  │ [Agent][Map][Split]   │ 任务状态     │
│ [InVEST]     │                      │ 运行日志     │
└──────────────┴──────────────────────┴─────────────┘
```

### 3.1 左栏·图层 Tab
- **屏上每个图层显示**：图层名、类型（栅格预览/矢量预览）、显隐开关、透明度滑块、缩放到图层按钮、移除按钮。
- **交互**：显隐切换、拖动调透明度、调整图层顺序、点击缩放到图层。
- 空态："地图上还没有图层"。

### 3.2 左栏·文件 Tab（轻量入口）
- **每个文件显示**：名称、类型、大小。
- **交互**：加入地图、作为 Agent 附件引用。
- 不展示完整元数据（完整元数据在数据管理页）。

### 3.3 左栏·InVEST Tab + 手动运行弹窗
- **列表显示**：模型名（Carbon Storage / Habitat Quality / Water Yield / Sediment Delivery Ratio / Nutrient Delivery Ratio），可标注"可运行/规划中"。
- **交互**：点击某模型 → 弹出**模型配置弹窗**。
- **模型配置弹窗（仅手动调用时出现）**：
  - 标题：模型名 + "模型配置"。
  - **输入数据**：按模型不同列出若干输入项（如 土地利用数据、碳密度表、研究区边界），每项是一个"从项目资产中选择"的下拉。
  - **参数设置**：输出目录、运行名称等；可含"运行模式"等可选项放进"高级选项"折叠区。
  - 底部：取消 / 运行模型；运行前可有"检查输入"按钮，结果以 错误/警告/通过 分级提示。
  - 提交后关闭弹窗，右栏出现运行状态与日志。

### 3.4 中央·Agent 视图（当前阶段＝纯聊天）

> **范围限定**：现在只画"能对话的聊天界面"。**不要画**自动选模型、自动跑模型、运行前确认卡片、工具调用中间态——那是后续阶段。

- **对话内容区**：纵向滚动的历史消息，含 用户消息 / Agent 回复；保持最新消息可见；Agent 回复**逐字追加**（流式）的视觉。
- **输入卡片**（底部）：
  - **附件展示区**（在文本框上方，无附件时不显示）：附件以标签形式 `landuse_2020.tif ×`，可移除。
  - **文本输入区**：多行，占位文案"描述你的地理分析任务，或询问当前项目数据与模型结果..."。
  - **底部工具栏**：附件按钮 + 对话模型选择器 + 发送按钮。
- **对话模型选择器**：下拉列出"已配置好的对话模型"（来自设置页），默认选中默认模型；**无已配置模型时**，禁用发送并提示"请先到设置页配置模型"。
- **附件来源**：本地上传 或 当前项目文件。
- **状态**：发送中（流式追加、禁止重复发送）、流出错（就近提示、可重试）、空会话态。

### 3.5 中央·Map 视图 / Split 视图
- **Map**：地图区（研究区边界、输入图层、模型输出、关注区域）；地图浮层小尺寸（标题/活动图层数、缩放按钮、要素属性卡、底部坐标/缩放）。
- **Split**：Agent 与地图同屏，用于"文字解释 + 空间结果"并置。
- 三视图切换为顶部分段控件。

### 3.6 右栏·运行信息（轻量）
- **任务状态**：只回答"当前是否有 InVEST 在跑"。
  - 无任务："当前无运行任务"。
  - 运行中："InVEST 正在运行" + 模型名。
  - 完成："运行完成" + 模型名。
  - 失败："运行失败，请查看日志"。
  - **不要**画进度条、资源消耗、多阶段步骤、"步骤 1/5"。
- **运行日志**：终端风格文本区，可滚动；失败时红色样式；带复制按钮；自动滚到底部。

## 4. 数据管理 / Data Hub

**布局**：顶部标题区 + 三栏（目录树 → 文件列表 → 文件详情）。

```
┌ 顶部导航 ─────────────────────────────────────────┐
│ 数据管理 / Data Hub    [搜索]  上传数据 新建文件夹 导入│
├──────────────┬──────────────────────┬─────────────┤
│ 数据目录树     │ 文件列表              │ 文件详情      │
└──────────────┴──────────────────────┴─────────────┘
```

### 4.1 顶部操作区
- 左：页面标题"数据管理 / Data Hub"。
- 右：搜索框、上传数据、新建文件夹、导入。

### 4.2 左·目录树
- 树形目录（如 raw / processed / outputs / documents / temp），可展开折叠、选中。
- 选中目录 → 中间文件列表切换到该目录内容。

### 4.3 中·文件列表
- **每个文件显示**：名称、类型（栅格/矢量/表格/文本/文件夹/其他）、大小。
- 选中文件 → 右侧出详情。
- 空目录态。

### 4.4 右·文件详情（只读元数据，不预览内容）
- **普通文件显示**：文件名、类型、格式、大小、创建时间、修改时间、路径、所属目录、编码、备注。
- **空间数据额外显示**：CRS、几何类型、要素数量、空间范围、分辨率、波段数量。
- 未选中文件时的空态。

> 边界：本页不做地图、内容预览、属性表、分析、模型运行。

## 5. Skills 管理

两层：列表页 → 详情页。

### 5.1 列表页
```
┌ 顶部导航 ─────────────────────────────────────────┐
│ Skills                              [搜索]  导入 Skill│
├──────────────────────────────────────────────────┤
│ Skills 列表（卡片/行）                              │
└──────────────────────────────────────────────────┘
```
- **每个 Skill 显示**：名称、一句话描述、更新时间。
- **交互**：搜索（仅名/描述）、导入 Skill、点击进入详情。

### 5.2 详情页
```
┌ 顶部导航 ─────────────────────────────────────────┐
│ Skills / carbon-storage-skill   （面包屑，首段可返回）│
├────────────────────┬─────────────────────────────┤
│ 文件结构（File Tree） │ 文件详情（File Detail）       │
└────────────────────┴─────────────────────────────┘
```
- **面包屑**：`Skills / {skill 名}`，点"Skills"返回列表。
- **左·文件结构**：目录/文件树，可展开折叠、选择文件（当前阶段不做编辑/拖拽）。
- **右·文件详情**：文件名、类型、路径、大小、修改时间、文件内容。
  - Markdown → 渲染显示；代码 → 只读代码块；JSON/文本 → 只读文本；二进制 → 只显示基本信息 + "该文件暂不支持内容预览"。
- **默认选中**：进入详情默认选 `SKILL.md`；没有则 `README.md`；都没有则空态"请选择一个文件查看详情"。

## 6. 设置 / Settings

**布局**：左（设置菜单）+ 右（设置内容）。默认选中"模型配置"。

```
┌ 顶部导航 ─────────────────────────────────────────┐
├──────────────┬───────────────────────────────────┤
│ 用户信息       │ 设置内容                           │
│ 模型配置       │                                   │
└──────────────┴───────────────────────────────────┘
```

### 6.1 用户信息
- **字段**：用户名、邮箱、机构、研究方向。
- 底部：保存按钮；保存后轻量提示"设置已保存"/失败提示。

### 6.2 模型配置（本页重点）

> 这里是 Agent 的**对话大模型**，不是 InVEST 模型。

- **模型列表**：每条显示 模型名称、供应商、是否默认、连接状态（已连接/未测试/连接失败 用不同色徽章）。
- **添加/编辑表单**字段：模型名称、供应商（OpenAI / Anthropic / DeepSeek / Qwen / Local / Custom）、**API Key（密码框，遮罩显示）**、Base URL、模型 ID、是否设为默认。
- **测试连接**：按钮 → 结果"连接成功"或"连接失败，请检查 API Key、Base URL 或模型 ID"。（原型只需表达按钮和成功/失败两种结果，不必表达内部如何测试。）
- **默认模型**：可设一个默认，供工作台 Agent 输入框默认选中。

## 7. 共享字段词汇表（让原型字段与未来数据对齐）

> 原型画字段时**用这套名字**，避免自造（如把"连接状态"画成"在线人数"），便于日后接后端。只列**屏上展示字段**。

- **文件/资产**：名称、类型(栅格/矢量/表格/文本/文件夹/其他)、大小、格式、CRS、几何类型、空间范围、要素数量、分辨率、波段数量、创建时间、修改时间、路径、所属目录、编码、备注。
- **图层**：图层名、类型(栅格/矢量)、是否可见、透明度、是否可缩放。
- **InVEST 模型**：模型名、状态(可运行/规划中)、描述、输入项列表、参数列表。
- **任务（InVEST 运行）**：状态(无任务/运行中/完成/失败)、模型名、运行名称、输出文件列表、日志文本。
- **对话模型（LLM）**：模型名称、供应商、是否默认、连接状态(已连接/未测试/连接失败)、API Key(遮罩)、Base URL、模型 ID。
- **对话**：消息角色(用户/Agent)、消息内容、附件列表、时间。
- **附件**：文件名、来源(本地/项目文件)。
- **Skill**：名称、一句话描述、更新时间；文件节点(名称/类型 文件或目录)；文件详情(文件名/类型/路径/大小/修改时间/内容)。
- **用户**：用户名、邮箱、机构、研究方向。

---

## 8. 原型阶段范围提醒

- **Agent 只做纯聊天**：消息流 + 输入卡片 + 附件 + 模型选择器。不画自动跑模型、确认卡片、工具调用中间态。
- **手动运行 InVEST 用弹窗**承载，不做常驻抽屉。
- 各页严守边界：数据管理只管数据资产；Skills 只读浏览；设置只管用户信息 + 模型配置；地图/运行/对话只在工作台。
- 每个数据区域都要画出 加载/空/错误/选中 四态。
