# GSMS 设置页面说明

## 1. 页面名称

页面名称：设置  
英文名称：Settings  
所属系统：GSMS  
页面类型：系统基础配置页面

---

## 2. 页面定位

设置页面用于管理 GSMS 的基础用户信息和 Agent 对话模型配置。

它主要回答两个问题：

```text
当前用户是谁？
Agent 可以使用哪些对话模型？
```

设置页面不负责数据管理、不负责模型运行、不负责 Agent 对话，也不负责 Skills 文件查看。

---

## 3. 页面主要功能

设置页面主要包含两类功能：

```text
用户信息设置；
模型配置。
```

其中，模型配置是本页面的重点。

智能工作台中 Agent 输入卡片里的模型选择器，应读取这里已经配置好的模型。

---

## 4. 页面基本布局

设置页面采用：

```text
顶部系统导航 + 左侧设置菜单 + 右侧设置内容
```

整体结构如下：

```text
┌──────────────────────────────────────────────┐
│ GSMS 顶部系统导航栏                           │
│ 工作台 | 数据管理 | Skills | 设置 | 用户       │
├──────────────┬───────────────────────────────┤
│ 设置菜单       │ 设置内容                       │
│ 用户信息       │                               │
│ 模型配置       │                               │
└──────────────┴───────────────────────────────┘
```

当前页面为设置页面，因此顶部导航中的“设置”处于选中状态。

---

## 5. 顶部系统导航

页面顶部为 GSMS 系统级导航栏。

导航栏包含：

```text
GSMS
工作台
数据管理
Skills
设置
用户入口
```

顶部导航只负责页面切换，不承载具体设置项。

---

## 6. 左侧设置菜单

左侧设置菜单用于切换不同设置分组。

菜单包含：

```text
用户信息
模型配置
```

默认进入设置页面时，可以默认选中“模型配置”，因为它与智能工作台关系最直接。

---

## 7. 用户信息设置

用户信息设置用于配置当前用户的基础信息。

建议包含：

```text
用户名
邮箱
机构
研究方向
```

示例：

```text
用户名：研究员
邮箱：user@example.com
机构：XXX University
研究方向：生态系统服务 / 土地利用变化
```

该区域只做基础信息维护，不做复杂账号、安全、权限管理。

---

## 8. 模型配置

模型配置用于管理 Agent 可以调用的对话模型。

需要注意：这里配置的是 Agent 使用的大语言模型，不是 InVEST 模型。

用户可以在这里添加、编辑和删除对话模型配置。

---

## 9. 模型配置列表

模型配置页面应展示用户已配置好的模型列表。

每个模型条目建议包含：

```text
模型名称
模型供应商
是否默认
连接状态
```

示例：

```text
Claude Sonnet
Anthropic
默认模型
已连接

GPT-4.1
OpenAI
备用模型
已连接

Qwen
阿里云
备用模型
未测试
```

智能工作台 Agent 输入框中的模型选择器，应读取这里已经配置好的模型。

---

## 10. 添加或编辑模型配置

用户点击“添加模型”或编辑某个模型时，进入模型配置表单。

表单建议包含：

```text
模型名称
模型供应商
API Key
Base URL
模型 ID
是否设为默认模型
```

示例：

```text
模型名称：Claude Sonnet
模型供应商：Anthropic
API Key：****************
Base URL：https://api.example.com
模型 ID：claude-sonnet-xxx
默认模型：是
```

模型供应商可以包括：

```text
OpenAI
Anthropic
DeepSeek
Qwen
Local Model
Custom
```

---

## 11. 模型连通性测试

模型配置中需要提供“测试连接”功能。

测试连接用于检查当前模型配置是否可用。

测试结果可以简单显示为：

```text
连接成功
```

或：

```text
连接失败，请检查 API Key、Base URL 或模型 ID
```

不要设计过于复杂的诊断面板。

---

## 12. 默认模型

用户可以设置一个默认模型。

默认模型用于：

```text
智能工作台 Agent 输入框的默认选中模型；
Agent 自动任务调用时的默认对话模型。
```

如果用户没有设置默认模型，则智能工作台需要提示用户先完成模型配置。

---

## 13. 保存设置

每个设置分组应提供保存按钮。

保存成功后显示轻量提示：

```text
设置已保存
```

保存失败时显示：

```text
保存失败，请检查配置内容
```

不需要额外设计复杂的版本管理或配置历史。

---

## 14. 页面边界

设置页面只负责用户信息和模型配置。

它不负责：

```text
数据文件管理；
地图展示；
Agent 对话；
InVEST 模型运行；
Skills 文件查看；
运行日志查看；
复杂用户权限管理；
系统监控；
数据路径配置。
```

这些功能应分别放在其他页面：

```text
数据文件管理 → 数据管理页面
Agent 对话、地图展示、InVEST 运行 → 智能工作台
Skills 文件查看 → Skills 页面
```

---

## 15. 设计原则

设置页面应保持简单、清楚、低干扰。

设计上强调：

```text
设置分组清晰；
用户信息简单；
模型配置易于填写；
连接测试结果明确；
不增加复杂高级设置。
```

---

## 16. 总结

GSMS 设置页面的核心是：

```text
用户信息
模型配置
```

其中模型配置最重要，因为它直接决定智能工作台中 Agent 输入卡片可选择哪些对话模型。

这个页面应保持克制，只承担用户基础信息维护和对话模型配置职责。
