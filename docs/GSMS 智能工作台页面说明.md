# GSMS 智能工作台页面说明

## 1. 页面名称

页面名称：智能工作台  
英文名称：Agent GIS Workbench  
所属系统：GSMS  
页面类型：Agent-first GIS 工作页面

---

## 2. 页面定位

智能工作台是 GSMS 系统中最核心的工作页面。

它不是传统意义上的地图页面，也不是单纯的聊天页面，而是一个以 Agent 对话为主要入口、以 InVEST 模型运行为核心能力、以 WebGIS 地图作为结果查看和空间交互环境的综合工作台。

这个页面主要帮助用户完成：

```text
通过 Agent 描述地理分析任务；
自动调用 InVEST 模型；
查看模型运行日志；
查看地图图层和模型结果；
必要时手动配置并运行 InVEST 模型。
```

页面的主路径是 Agent 自动理解用户任务，并自动完成 InVEST 模型选择、数据匹配、参数配置和模型运行。

手动调用 InVEST 模型是低频备用能力。

---

## 3. 页面主要功能

智能工作台主要包含五类功能。

### 3.1 Agent 对话与任务发起

用户可以在中央 Agent 对话区直接输入自然语言任务。

例如：

```text
请使用 InVEST Carbon Storage 模型计算当前研究区的碳储量。
```

Agent 负责理解用户意图，自动识别需要调用的 InVEST 模型，自动匹配输入数据和参数，并直接发起模型运行。

Agent 调用模型时，不弹出模型配置窗口，也不要求用户手动确认。

### 3.2 当前项目资源查看

用户可以在左侧资源面板中查看当前项目相关资源。

资源包括：

```text
图层
文件
InVEST
```

图层用于管理地图中显示的数据；文件用于查看当前项目可用的数据；InVEST 用于提供手动模型调用入口。

### 3.3 地图查看与结果展示

中央区域支持地图查看。

地图用于展示：

```text
研究区边界；
输入数据图层；
InVEST 模型输出结果；
用户关注的空间区域。
```

地图不是页面唯一中心，但它是模型结果查看和空间验证的重要区域。

### 3.4 InVEST 模型运行

InVEST 模型有两种调用方式：

```text
Agent 自动调用；
用户手动调用。
```

Agent 自动调用是主要方式。

用户手动调用是备用方式，用于用户希望自己选择模型、输入数据和参数的情况。

### 3.5 运行状态与日志查看

页面右侧提供轻量的模型运行信息区域。

它主要用于提示用户当前是否有 InVEST 任务正在运行，并展示模型运行日志。

右侧区域不做复杂任务管理，不展示冗余执行状态字段。

---

## 4. 页面基本布局

智能工作台采用：

```text
顶部系统导航 + 三栏主体布局
```

整体结构如下：

```text
┌──────────────────────────────────────────────┐
│ GSMS 顶部系统导航栏                           │
│ 工作台 | 数据管理 | Skills | 设置 | 用户       │
├──────────────┬────────────────┬──────────────┤
│ 左侧资源面板  │ 中央智能画布     │ 右侧运行信息   │
│ 图层/文件/InVEST│ Agent / Map / Split │ 状态/日志     │
└──────────────┴────────────────┴──────────────┘
```

页面顶部只保留系统级导航栏，不额外增加复杂任务工具栏。

不在顶部长期放置“当前任务”“运行”“停止”“导出”等按钮。

这些操作应出现在具体对话、模型配置弹窗、结果卡片或图层操作中。

---

## 5. 顶部系统导航

页面顶部为 GSMS 系统级导航栏。

导航栏中包含：

```text
GSMS
工作台
数据管理
Skills
设置
用户入口
```

当前页面为智能工作台，因此“工作台”导航项需要处于选中状态。

系统级导航栏只承担页面切换作用，不承担模型运行控制作用。

---

## 6. 左侧资源面板

左侧资源面板用于展示当前工作台可用的项目资源。

它采用轻量 Tab 切换形式，包含：

```text
图层
文件
InVEST
```

左侧面板不是完整的数据管理页，也不是完整模型管理页，而是工作台内的资源入口。

---

## 7. 图层 Tab

图层 Tab 用于展示当前地图中已经加载的图层。

例如：

```text
study_area
landuse
carbon_storage_result
habitat_quality_result
```

用户可以在这里进行基础图层控制，例如：

```text
显示 / 隐藏；
调整透明度；
调整图层顺序；
缩放至图层。
```

图层 Tab 的主要作用是配合中央地图查看输入数据和模型结果。

---

## 8. 文件 Tab

文件 Tab 用于展示当前项目中可供工作台使用的数据文件。

它是数据管理页面的轻量入口，不需要展示完整文件管理功能。

用户可以从这里了解当前项目有哪些数据，也可以选择某个数据作为当前任务的输入参考。

文件 Tab 不承担复杂元数据查看职责，详细数据管理仍放在数据管理页面完成。

---

## 9. InVEST Tab

InVEST Tab 用于展示当前系统支持的 InVEST 模型模块。

例如：

```text
Carbon Storage
Habitat Quality
Water Yield
Sediment Delivery Ratio
Nutrient Delivery Ratio
```

用户可以从这里手动选择某个 InVEST 模型进行运行。

需要注意的是，InVEST Tab 不是一个泛化模型库，也不需要设计成复杂模型市场。它只是当前工作台中手动调用 InVEST 模型的入口。

---

## 10. 中央智能画布

中央区域是智能工作台的核心区域。

它支持三种视图：

```text
Agent
Map
Split
```

默认进入页面时，建议显示 Agent 视图。

---

## 11. Agent 视图

Agent 视图是智能工作台的默认入口。

它由两部分组成：

```text
对话内容区；
输入卡片。
```

对话内容区用于展示用户与 Agent 的历史对话。

输入卡片用于让用户输入新任务、选择对话模型、添加附件并发送消息。

---

## 12. Agent 对话内容区

对话内容区用于展示用户和 Agent 的历史对话。

它只承担基础对话展示职责，不在当前阶段设计复杂任务卡片、工具调用中间态或结果解释组件。

对话内容区应展示：

```text
用户消息；
Agent 回复；
历史对话记录。
```

对话内容区需要支持纵向滚动，并保持最新消息可见。

---

## 13. Agent 输入卡片

Agent 输入卡片位于 Agent 视图底部。

输入卡片采用轻量结构：

```text
┌──────────────────────────────────────────────┐
│ 输入卡片                                      │
│ [ landuse_2020.tif × ] [ carbon_table.csv × ] │
│                                              │
│ 描述你的地理分析任务，或询问当前项目数据...     │
│                                              │
│ + 附件        模型：Claude Sonnet ▼    [发送] │
└──────────────────────────────────────────────┘
```

输入卡片包括：

```text
附件展示区；
文本输入区；
底部工具栏。
```

### 13.1 附件展示区

附件展示在输入卡片内部，位于文本输入区上方。

当用户没有添加附件时，附件展示区不显示。

当用户添加附件后，附件以轻量标签形式展示，例如：

```text
landuse_2020.tif ×
carbon_table.csv ×
study_area.shp ×
```

每个附件标签支持移除。

### 13.2 文本输入区

文本输入区用于输入自然语言任务或问题。

占位文案为：

```text
描述你的地理分析任务，或询问当前项目数据与模型结果...
```

文本输入区支持多行输入。

### 13.3 底部工具栏

输入卡片底部工具栏包含：

```text
附件按钮；
模型选择器；
发送按钮。
```

附件按钮用于添加附件。

模型选择器用于选择用户已经在设置页面中配置好的对话模型。

发送按钮用于提交当前输入内容、所选模型和附件列表。

---

## 14. 对话模型选择

输入卡片中提供对话模型选择器。

这里的模型是用户在设置页面中已经配置好的大模型，而不是 InVEST 模型。

例如：

```text
Claude Sonnet
GPT
DeepSeek
Qwen
Local Model
```

用户只能选择已经配置好的模型。

如果用户尚未配置模型，应提示用户先前往设置页面完成模型配置。

---

## 15. 附件添加

输入卡片支持添加附件。

附件可以来自：

```text
本地上传；
当前项目文件。
```

附件用于辅助用户描述任务，或作为 Agent 判断和执行任务时的输入参考。

附件展示在输入卡片内部，不作为历史对话内容展示。

---

## 16. Map 视图

Map 视图用于展示地图和空间结果。

地图中可以展示：

```text
研究区边界；
输入数据图层；
InVEST 输出结果；
用户关注区域。
```

Map 视图主要用于查看和验证模型结果。

用户可以通过左侧图层 Tab 控制地图中的图层显示。

---

## 17. Split 视图

Split 视图用于同时展示 Agent 和地图。

它适合在模型运行完成后查看结果解释。

例如，左侧或下方展示 Agent 对结果的文字解释，右侧或上方展示地图结果。

Split 视图的作用是把“文字解释”和“空间结果”放在同一个上下文中，方便用户理解模型输出。

---

## 18. 右侧运行信息面板

右侧运行信息面板用于展示 InVEST 运行状态和运行日志。

它包含两个部分：

```text
任务状态；
运行日志。
```

该区域应保持轻量，不做复杂的执行状态设计。

---

## 19. 任务状态

任务状态只回答一个问题：

```text
当前是否有 InVEST 模型正在运行？
```

无任务时显示：

```text
当前无运行任务
```

运行中显示：

```text
InVEST 正在运行
Carbon Storage
```

运行完成显示：

```text
运行完成
Carbon Storage
```

运行失败显示：

```text
运行失败
请查看日志
```

任务状态不需要长期展示过多字段。

不建议展示：

```text
复杂进度条；
资源消耗；
多阶段步骤；
模型版本；
输入输出完整清单；
步骤 1/5。
```

这些信息如有必要，可出现在日志或 Agent 对话中。

---

## 20. 运行日志

运行日志是右侧面板中更重要的部分。

它用于展示 InVEST 模型运行过程中的文本日志。

例如：

```text
[10:21:01] Start InVEST Carbon Storage
[10:21:04] Loading landuse_2020.tif
[10:21:08] Loading carbon_table.csv
[10:21:15] Running model...
[10:22:03] Writing output raster
[10:22:10] Finished successfully
```

日志区域需要便于用户判断模型是否正常运行，以及错误发生在哪里。

运行日志应支持基本的滚动查看。

---

## 21. InVEST 模型调用方式

InVEST 模型调用分为两种方式：

```text
Agent 自动调用；
用户手动调用。
```

这两种方式面向不同使用场景。

---

## 22. Agent 自动调用 InVEST

Agent 自动调用是主要路径。

用户在中央 Agent 输入卡片中提出任务后，Agent 自动完成模型选择、数据匹配、参数配置和模型运行。

基本流程为：

```text
用户输入任务
→ 用户选择对话模型
→ 用户可选择添加附件
→ Agent 理解任务
→ Agent 选择 InVEST 模型
→ Agent 匹配输入数据
→ Agent 自动生成参数
→ Agent 直接运行模型
→ 右侧显示运行状态和日志
→ 结果加入地图图层
→ Agent 在对话区返回说明
```

Agent 自动调用时：

```text
不弹出模型配置窗口；
不要求用户手动确认；
不要求用户逐项填写参数；
不打断中央 Agent 工作流。
```

---

## 23. 用户手动调用 InVEST

用户手动调用是低频备用能力。

当用户希望自己选择模型、输入数据和参数时，可以从左侧 InVEST Tab 中点击某个模型。

点击模型后，系统弹出模型配置弹窗。

基本流程为：

```text
用户进入左侧 InVEST Tab
→ 用户选择某个 InVEST 模型
→ 系统弹出模型配置窗口
→ 用户填写输入数据和参数
→ 用户点击运行模型
→ 右侧显示运行状态和日志
→ 结果生成后加入地图图层
```

由于手动调用不是主路径，因此不需要为它设计长期占据页面空间的抽屉面板。

采用弹窗更合适。

---

## 24. 模型配置弹窗

模型配置弹窗只在用户手动调用 InVEST 模型时出现。

弹窗用于让用户配置：

```text
输入数据；
模型参数；
输出目录；
运行名称。
```

示例结构：

```text
┌──────────────────────────────┐
│ InVEST Carbon Storage         │
│ 模型配置                       │
├──────────────────────────────┤
│ 输入数据                       │
│ 土地利用数据    [选择文件]      │
│ 碳密度表        [选择文件]      │
│ 研究区边界      [选择文件]      │
│                              │
│ 参数设置                       │
│ 输出目录        [选择目录]      │
│ 运行名称        [carbon_run_01] │
│                              │
│ [取消]        [运行模型]       │
└──────────────────────────────┘
```

不同 InVEST 模型的输入项和参数项可以不同。

弹窗只负责手动配置，不用于 Agent 自动调用流程。

---

## 25. 模型运行后的结果处理

无论模型是由 Agent 自动调用，还是由用户手动调用，运行完成后都应进入同一套结果处理逻辑。

运行完成后：

```text
右侧任务状态显示运行完成；
运行日志显示完成信息；
模型输出结果加入左侧图层列表；
地图中可以查看输出结果；
Agent 可以在对话区对结果进行说明。
```

结果导出按钮不需要长期放在顶部，可以出现在结果消息、图层操作菜单或文件输出位置中。

---

## 26. 页面边界

智能工作台负责 Agent 对话、InVEST 模型运行、地图查看和运行日志展示。

它不负责以下内容：

```text
完整文件管理；
完整元数据管理；
Skills 文件管理；
模型供应商配置；
用户个人设置。
```

这些功能应放在其他页面中：

```text
完整文件管理和元数据查看 → 数据管理页面
Skills 管理 → Skills 页面
模型配置和 API Key 设置 → 设置页面
```

---

## 27. 设计原则

智能工作台应保持 Agent-first 的设计方向。

设计上应遵循：

```text
顶部保持简洁；
中央区域作为核心交互区域；
Agent 是默认入口；
输入卡片支持模型选择和附件添加；
地图用于结果查看和空间验证；
右侧只显示轻量状态和运行日志；
手动模型调用使用弹窗承载；
不做复杂任务管理界面。
```

页面不应被过多按钮、状态字段和任务栏占据。

---

## 28. 总结

GSMS 智能工作台的核心是：

```text
左侧提供资源；
中央完成 Agent 对话与地图交互；
右侧显示 InVEST 运行信息。
```

InVEST 模型调用分为两种方式：

```text
Agent 调用：自动配置并直接运行，不需要用户确认；
手动调用：用户从左侧 InVEST 入口选择模型，通过弹窗配置输入和参数后运行。
```

Agent 输入区采用输入卡片形式：

```text
附件标签在输入卡片内部、文本输入区上方；
文本输入区用于描述任务；
底部工具栏提供附件添加、模型选择和发送按钮。
```

这个页面应保持轻量、聚焦，突出 Agent-first 的使用体验，同时保留必要的 WebGIS 图层查看和 InVEST 手动运行能力。
