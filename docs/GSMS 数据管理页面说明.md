# GSMS 数据管理页面说明

## 1. 页面定位

数据管理页面是 GSMS 系统中用于管理项目数据资产的基础页面。

它主要用于帮助用户查看、组织和管理项目中的各类数据文件，包括空间数据和普通数据文件。

这个页面的核心不是分析数据，也不是展示地图，而是让用户清楚地知道：

```text
数据放在哪个目录中；
当前目录下有哪些文件；
某个文件的基本元数据是什么。
```

因此，数据管理页面承担的是“数据资产管理”的职责。

---

## 2. 页面主要功能

数据管理页面主要包含三个功能：

### 2.1 管理数据目录

用户可以通过数据目录树查看当前项目下的数据组织结构。

例如：

```text
Project A
├── raw
├── processed
├── outputs
├── documents
└── temp
```

用户可以在不同目录之间切换，从而查看不同目录下的数据文件。

### 2.2 查看目录中的文件

用户选择某个目录后，页面中间区域会展示该目录下的文件列表。

文件列表只展示最基础的文件信息，包括：

```text
名称
类型
大小
```

例如：

```text
rainfall_2022.tiff    栅格    128MB
landuse.shp           矢量    42MB
census.csv            表格    8MB
```

文件列表的作用是让用户快速了解当前目录下有哪些数据，而不是在这里查看复杂的数据内容。

### 2.3 查看文件元数据

用户点击文件列表中的某个文件后，页面右侧会展示该文件的元数据信息。

元数据用于描述文件本身的基本情况，例如：

```text
文件名称
文件类型
文件格式
文件大小
创建时间
修改时间
文件路径
所属目录
```

对于空间数据，还可以展示：

```text
CRS
几何类型
空间范围
要素数量
分辨率
波段数量
```

文件详情区域只展示元数据，不展示文件内容本身。

---

## 3. 页面基本布局

数据管理页面采用：

```text
顶部系统导航 + 三栏主体布局
```

整体结构如下：

```text
┌──────────────────────────────────────────────┐
│ GSMS 顶部系统导航栏                           │
│ 工作台 | 数据管理 | Skills | 设置 | 用户       │
├──────────────────────────────────────────────┤
│ 数据管理 / Data Hub                           │
│ 搜索框                  上传数据 新建文件夹 导入│
├──────────────┬────────────────┬──────────────┤
│ 数据目录树    │ 文件列表         │ 文件详情       │
│              │                │              │
└──────────────┴────────────────┴──────────────┘
```

---

## 4. 顶部系统导航

页面顶部为 GSMS 的系统级导航栏。

导航栏中包含：

```text
GSMS
工作台
数据管理
Skills
设置
用户入口
```

当前页面为数据管理页面，因此“数据管理”导航项需要处于选中状态。

系统级导航栏放在页面上方，不使用左侧系统导航栏。这样可以让主体区域更完整地用于目录、文件和元数据展示。

---

## 5. 页面标题与操作区

顶部导航栏下方是数据管理页面的标题与操作区。

左侧显示页面标题：

```text
数据管理 / Data Hub
```

右侧提供常用操作：

```text
搜索框
上传数据
新建文件夹
导入
```

搜索框用于搜索文件或目录名称。

上传数据用于向当前目录上传数据文件。

新建文件夹用于在当前目录下创建新的文件夹。

导入用于从外部路径或其他数据来源导入数据。

---

## 6. 三栏主体结构

页面主体分为三栏：

```text
左侧：数据目录树
中间：文件列表
右侧：文件详情
```

三栏之间的关系是：

```text
数据目录树 → 文件列表 → 文件详情
```

也就是说：

用户先在左侧选择目录；  
中间显示该目录下的文件；  
用户再选择某个文件；  
右侧显示该文件的元数据。

---

## 7. 左侧：数据目录树

左侧区域用于展示当前项目的数据目录结构。

它的主要作用是帮助用户定位数据所在目录。

例如：

```text
Project A
├── raw
├── processed
├── outputs
├── documents
└── temp
```

用户点击某个目录后，中间的文件列表会切换为该目录下的文件内容。

数据目录树只负责目录导航，不负责展示文件详细信息。

---

## 8. 中间：文件列表

中间区域用于展示当前目录下的文件。

文件列表只展示基础信息：

```text
名称
类型
大小
```

其中，类型可以按照文件性质进行归类，例如：

```text
栅格
矢量
表格
文本
文件夹
其他
```

文件列表的目标是保持简洁，让用户快速判断当前目录下有哪些数据文件。

---

## 9. 右侧：文件详情

右侧区域用于展示当前选中文件的元数据。

文件详情不展示数据内容本身，只展示用于描述文件的信息。

普通文件可以展示：

```text
文件名称
文件类型
文件格式
大小
创建时间
修改时间
路径
所属目录
编码
备注
```

空间数据可以额外展示：

```text
CRS
几何类型
要素数量
空间范围
分辨率
波段数量
```

文件详情区域的作用是帮助用户确认文件的基本情况，而不是直接查看或编辑数据内容。

---

## 10. 页面边界

数据管理页面只负责数据资产管理。

它不负责以下内容：

```text
地图预览
数据内容预览
属性表查看
空间分析
模型运行
Agent 对话
Agent 可用性展示
Skills 管理
模型配置
```

这些功能应放在 GSMS 的其他页面中。

其中：

```text
地图预览、空间分析、模型运行、Agent 对话 → 工作台页面
Skills 管理 → Skills 页面
模型配置 → 设置页面
```

---

## 11. 设计原则

数据管理页面应保持克制、清晰和专业。

设计上应强调：

```text
目录结构清楚
文件列表简洁
元数据信息明确
页面层级清晰
科研系统风格
```

不应增加过多解释性模块，也不应在页面底部增加流程提示条。

---

## 12. 总结

GSMS 数据管理页面的核心是：

```text
目录 → 文件 → 元数据
```

用户通过左侧目录树定位数据目录，通过中间文件列表查看当前目录下的文件，通过右侧文件详情查看选中文件的元数据。

这个页面应专注于数据资产管理，保持简洁，不承担地图展示、数据分析或 Agent 交互功能。
